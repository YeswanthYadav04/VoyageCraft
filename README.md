# 🌍 VoyageCraft – Personalized Travel Planning Made Easy

VoyageCraft is a smart and interactive travel planning platform designed to simplify the way people organize and experience trips. From building multi-city itineraries to tracking budgets and managing activities, VoyageCraft helps travelers plan every detail in one place.

Whether you are planning a solo adventure, a family vacation, or a group trip, VoyageCraft provides an intuitive and user-friendly experience for creating personalized travel journeys.

# 🎯 Problem Statement

Planning trips across multiple destinations can become complicated when managing:

* Cities
* Activities
* Dates
* Budgets
* Notes
* Packing lists

VoyageCraft solves this problem by providing an all-in-one travel planning ecosystem where users can efficiently organize every aspect of their journey through an interactive and responsive platform.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/your-username/voyagecraft.git
```

## Navigate to Project

```bash
cd voyagecraft
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
